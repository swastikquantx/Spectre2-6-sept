# Data Classification

## Classes
1. **PUBLIC**: Safe for external sharing (e.g., SEO pages).
2. **INTERNAL**: Employee/system data not strictly confidential.
3. **CONFIDENTIAL**: Customer data, prompts, AI generated IP.
4. **RESTRICTED**: Secrets, PII, financial details.

## AI Handling
Restricted data must NEVER be sent to third-party AI models without redaction or explicit tenant approval.

# Incident Response

## Severity Levels
- **SEV-1**: Critical outage / data breach.
- **SEV-2**: Degraded performance / major feature broken.
- **SEV-3**: Minor bug / isolated issue.

## Procedure
1. Identification & Logging
2. Containment (Rollback or Feature Flag toggle)
3. Mitigation
4. Post-Mortem Analysis
